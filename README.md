ReCon - Control your context together.


AI coding agents can build features, but their sessions are solo, fragile, and disposable. Teams cannot steer the same agent together. As conversations grow, context rot degrades performance; compacting can erase decisions; and when an agent goes down the wrong path, the context and code state that produced it are lost.

ReCon is a multiplayer workspace where developers co-edit the prompt, watch the agent work live, inspect tool calls and file changes, and pause, redirect, or resume execution together.

Underneath, ReCon is version control for agent context. Every turn becomes an exact checkpoint of the literal request sent to the model, its response, tool outputs, and workspace snapshot. Any collaborator can instantly restore that moment, fork parallel approaches, or prune irrelevant history into a leaner branch while preserving provenance.

ReCon turns AI coding from isolated chats into persistent, collaborative infrastructure for engineering organizations.
